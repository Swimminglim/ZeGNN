# Empirical datasets

| File | Application | Description |
| --- | --- | --- |
| `kc_house_data.csv` | Housing | King County house sales data |
| `Mental_health.csv` | Mental Health | Author-processed neighborhood-level sociodemographic, mental health, and place-based variables |
| `PM25_June2023_Mean.csv` | PM2.5 | Author-processed June 2023 PM2.5 and meteorological data |

The original data sources and variable descriptions are documented in the manuscript and supporting information. The simulation scripts generate synthetic data directly and do not require pre-generated CSV files.
